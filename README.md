Project Name: AI Subscription Model

Description: A web platform for exploring and subscribing to AI-powered digital tools with interactive cart and subscription options.

Technology used: 
React.js, HTML5, Tailwind CSS & DaisyUI, JavaScript (ES6+), React-Toastify, JSON

3 Features:
Interactive Product Catalog – Browse AI tools with detailed descriptions, pricing, tags, and features.
Dynamic Cart Functionality – Add, remove, and manage products in the cart with real-time updates.
Responsive Design – Fully responsive layout that works smoothly across all devices.
